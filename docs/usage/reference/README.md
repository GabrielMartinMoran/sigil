# User reference

Use these pages to look up exact names, syntax, and defaults. If you're still
setting up Sigil, start with [Get started](../getting-started/README.md)
instead.

## Find a command or setting

Each reference covers a different kind of input:

- [Commands](commands.md): slash commands in the terminal prompt.
- [Keyboard shortcuts](keyboard.md): composing, navigation, questions, and
  agents.
- [Environment variables](environment.md): startup settings and data paths.
- [Configuration files](../configuration/files-and-directories.md): locations
  and precedence.
- [MCP fields](../configuration/mcp.md#fields): transport and server settings.
- [Agent profile fields](../customization/agents.md#the-file): frontmatter and
  permissions.

Run `/help` in the terminal for the command list available in your build.
