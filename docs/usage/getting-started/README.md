# Get started with Sigil

Follow this path to run Sigil in your project and complete your first
conversation. You need a supported Python environment and access to one of the
supported model providers; you don't need a Sigil account.

## Your first run

Complete these two guides in order:

1. [Install and launch Sigil](installation.md): prepare the checkout and open
   your project in the terminal.
2. [Start your first conversation](first-conversation.md): connect a provider,
   select a model, and ask for a small investigation.

The result is a working conversation in the correct project directory. You can
then [learn the terminal controls](../guides/terminal.md),
[open the browser client](../guides/browser.md), or
[configure defaults](../configuration/README.md).

## If setup fails

Use [Troubleshooting](../troubleshooting/README.md) for missing prerequisites,
provider problems, and server conflicts. Don't put provider keys into project
files to get past an account-setup problem.
