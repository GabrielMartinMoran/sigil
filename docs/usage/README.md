# Use Sigil

This is the user path: install Sigil, connect a model, and work on your project.
Architecture and implementation details live in the separate
[technical documentation](../technical/README.md).

## First time here?

Follow [Get started](getting-started/README.md). It takes you from the
prerequisites to your first conversation, with checks at each stage.

## Choose your next task

You can go directly to the area you need:

- [Configure Sigil](configuration/README.md): accounts, models, paths, and MCP.
- [Work with Sigil](guides/README.md): terminal, browser, conversations,
  sessions, rollback, cost, and notifications.
- [Customize Sigil](customization/README.md): agents, skills, extensions,
  project instructions, and themes.
- [Look something up](reference/README.md): commands, shortcuts, and settings.
- [Resolve a problem](troubleshooting/README.md): setup and service recovery.

For the limits of file access and tool permissions, read
[Permissions and safety](guides/safety.md).
