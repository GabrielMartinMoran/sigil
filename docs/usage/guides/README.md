# Work with Sigil

These guides focus on completing tasks, not on implementation. Choose the
interface or workflow you need; you don't have to read them in order.

## Talk to your agent

Use the controls for the interface you opened:

- [Terminal controls](terminal.md): messages, images, questions, and display.
- [Browser client](browser.md): start the web surface and sign in.
- [Conversations](conversations.md): steer a running turn and stop safely.
- [Subagents](subagents.md): inspect delegated work and stop a branch.

## Manage your work

Keep conversations organized and understand what a change will affect:

- [Sessions and workspaces](sessions.md): resume work or create a Git worktree.
- [Rollback and forks](rollback.md): return to an earlier turn or branch the
  chat.
- [Context and cost](context-and-cost.md): read usage and compact a
  conversation.
- [Notifications](notifications.md): enable alerts and understand their limits.
- [Permissions and safety](safety.md): know what tool access does and doesn't
  restrict.

For exact syntax, use the
[command and keyboard reference](../reference/README.md).
