# Evaluation

Software tests establish implementation behavior. They don't establish that a
model uses tools more accurately or that a task costs less with a provider.

## Choose the evidence you need

Use [Tool-use evaluation](tool-use.md) for the offline scripted workflow and
explicit live-model comparisons. Live mode makes provider requests and can incur
charges; it isn't part of routine documentation verification.

Use [Performance](../performance/README.md) for local runtime measurements and
[Testing](../development/testing.md) for deterministic correctness checks.
