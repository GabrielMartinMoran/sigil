## Work with an agent, not around one

Ask Sigil to investigate a bug, explain unfamiliar code, or implement a change.
It can read and edit files, run commands, research the web, and bring in
specialized agents while you follow the work.

- **Choose the models that fit the task.** Connect OpenRouter, OpenCode, or
  OpenAI accounts. Change models and supported reasoning levels between turns.
- **Keep the conversation moving.** Send a correction while the agent works,
  answer questions in place, and inspect what its tools are doing.
- **Pick up where you left off.** Resume saved conversations with their model,
  agent, and work history. Use separate Git worktrees for parallel changes.
- **Make it yours.** Add agent profiles, Agent Skills, MCP servers, local tools,
  and themes without changing Sigil's core.

## One project, two ways in

Use the **terminal** for a keyboard-first workspace, or the **browser** to work
through the web client. Both connect to the same local service and saved state.

Sigil stores its state locally. Model requests go to your chosen provider;
connected tools can also access external services. Your provider's pricing and
access requirements still apply.
